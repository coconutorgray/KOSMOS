## 질문 (돌리기 전에 쓴다)

프롬프트당 표본 수 k=100은 비용 부담이 크다(DeepSeek 추론·인칭·화계 같은 새 수집에 그대로 들어감). (1) k를 얼마까지 줄여도 전체 데이터(k≈100)의 보정 후 validation TVD와 모델 순서가 재현되는가? (2) 작은 k에서 잰 TVD 곡선으로 k=100 값을 통계적으로 근사(외삽)할 수 있는가?

## 가설과 판정 기준 (돌리기 전에 쓴다)

기준값 = 전체 데이터(DeepSeek·Haiku k=100, EXAONE k 93~99)로 calibration에서 β를 고르고 잰 validation TVD. 단위는 (모델 3 × 단계 c0·L0·L1) 9칸.

- **H1 (재현에 필요한 k):** k* ≤ 30이다.
  - k*는 아래 A·B를 모두 만족하는 격자 안의 가장 작은 k다.
  - A(TVD 재현): 9칸 모두에서 반복 10회 중 9회 이상이 `TVD_k − TVD_full ≤ 0.01`.
  - B(순서 재현): 단계마다, 전체 데이터에서 TVD 차이가 0.005 이상인 모델 쌍의 순서가 반복 10회 중 9회 이상 그대로다. 0.005 미만인 쌍은 사실상 동률이라 판정에서 뺀다.
  - 지지: k* ≤ 30. 기각: k* > 30 또는 격자 안에서 k*가 없음.
- **H2 (통계적 근사):** 작은 k(5·10·15·20·30)의 반복 평균 TVD에 `TVD(k) = c + a/√k`를 최소제곱으로 맞추고 모델별 전체 k(프롬프트별 유효 응답 수의 중앙값)에서 예측하면, 9칸 모두 `|예측 − TVD_full| ≤ 0.005`다.
  - 비교용 단순 근사: k=30에서 잰 TVD를 그대로 쓰는 것. 외삽이 이보다 오차가 작은지 같이 본다.
  - 지지: 9칸 모두 0.005 이내. 기각: 한 칸이라도 넘음.
- 쓰는 문항 분할: calibration(β 고르기) / validation(확인). test는 쓰지 않는다.

## 방법

`20261115-k-curve`와 같은 방식이다. count 벡터에서 비복원 추출(다변량 초기하)로 프롬프트당 k개를 뽑는다(유효 응답이 k보다 적으면 있는 만큼). k ∈ {5, 10, 15, 20, 30, 40, 50, 70}, 반복 10회(시드 고정). 매 (k, 반복)마다 calibration 148문항으로 β를 다시 고르고(그리드 0.05~1.5, 0.01 간격) validation 49문항 TVD를 잰다. 보정은 라플라스 α=1, p ∝ (c+1)^β.

- 외삽은 k=30 값을 그대로 쓰는 것보다 9칸 중 7칸에서 오차가 작다(최대 오차 0.0087 vs 0.0117). 넘는 칸은 모두 예측이 전체 데이터보다 높다. k가 커질 때 1/√k보다 더 빨리 내려간다는 뜻이다.

## 결론

H1 기각: TVD와 순서를 함께 재현하려면 k\*=50이 필요하다(k ≤ 30 아님). 순서만이라면 k=30이면 충분하고, Haiku는 k=5로도 된다. H2 기각: k≤30에서 c+a/√k로 외삽하면 9칸 중 6칸만 0.005 이내다(최대 0.0087, L0의 EXAONE·DeepSeek). 다만 k=30 값을 그대로 쓰는 것보다는 대체로 낫다.

새 수집에 대한 함의: 모델 간 **순서·방향**만 볼 실험(예: 추론 on/off가 페르소나 반응을 바꾸는가)은 k=30이면 판단이 바뀌지 않았다. TVD **수치 자체**를 k=100 결과와 나란히 보고할 실험은 k=50이 필요하다. Haiku는 k를 늘려도 이득이 거의 없다.

한계:
- 부분표본은 같은 k≈100 데이터에서 뽑아서 k가 클수록(특히 70) 반복끼리, 그리고 기준값과 독립이 아니다. k=50·70의 통과는 낙관적일 수 있다.
- 기존 DeepSeek(추론 끔)·Haiku·EXAONE 데이터로 잰 값이다. 추론을 켜거나 프롬프트(인칭·화계)를 바꾸면 응답 분산이 달라져 필요한 k도 달라질 수 있다. 새 실험의 파일럿에서 다시 확인해야 한다.
- 문항 수가 calibration 148·validation 49로 고정이다. 문항을 줄이는 쪽의 비용 절감은 보지 않았다.
